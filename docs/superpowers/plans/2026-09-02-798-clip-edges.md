# #798 — the clip guards' remaining edges

Redmine #798. Four findings #796 left open; the probe
(`evals/clip_edges_probe_798.py`, findings in `evals/clip_edges_probe_798/`)
was written BEFORE any design, per the rule #796 earned, and it widened two
of them.

## What the probe measured (Maya 2027, agent session on 9878)

**A. clean_clip vs a set-driven key.** `_keyed_plugs` returned the driven
plug. `getAttr(plug, time=f)` on it answers the driver's constant (12.32) at
every f; `setKeyframe` returns 0 every time; the driver-indexed keys survive
untouched. So the harm is a false count ("smoothed 4 channel(s)" for 3) and
31 wasted writes — not destruction. Fix: the CLIP partition, plus reading
the re-key's return.

**B. retarget then author.** walk01 baked 0–150 on the 15 slot joints
(rotate, translate AND scale curves on every one — scale and non-root
translate are constant), record `joints: []`. idle authored 152–212
declaring `head` (a slot joint). Every sampled slot channel held walk01's
LAST value across idle with no key at 152 or 212. And the other half: idle's
back-fill of `head` over walk01's boundaries pinned it at the bake's FIRST
key (no rest recorded), so walk01's frame 150 head value became its frame 0
value — an earlier clip's motion changed, which the #718 rule forbids.

**C. a locked root.translateY.** author_clip returned `root_position_keyed:
True`. `xform -translation` wrote X and Z and dropped Y WITHOUT raising;
`setKeyframe` on the locked child returned 0; the lost-write note ended
"see the note naming what drives it" with no such note. `getAttr(lock=True)`
is per child — the compound answers False. A locked rotate child behaves
the same (setKeyframe 0, setAttr raises).

**D. the blend walk.** 60-joint chain, one clip, re-authored:
`cut_replaced_range` issued 2130 `listConnections` in 0.068 s with the walk
and 360 in 0.020 s without; the whole re-author was 0.22 s over the wire.
Not worth a cache. Recorded in protocol.md; no code change.

## Design

1. **cleanclip** — `_keyed_plugs` asks `clip.clip_curve_plugs`; the filter
   pass reads `setKeyframe`'s return (`clip.key_landed`), names a vanished
   re-key with its cause, and counts only channels that landed.
2. **The pass is one function.** author_clip's closures (`_pin_plugs`,
   `_pin`, `_pad_boundaries`, `_back_fill`) and the pad/back-fill loops are
   `clip.make_self_contained(cmds, what, root_long, joints, alias_map,
   start_frame, end_frame, measured_end, kept, mine, rest, warnings)`,
   returning `padded_channels`/`held_channels`/`back_filled`. author_clip's
   behaviour is unchanged (its 100+ tests are the proof).
   retarget_clip: `_rest_at_stance` captures the slot joints' rotate rest
   and the root's translate rest inside the existing stance window (curves
   disconnected there, so `_capture_rest` reads the stance rather than
   skipping); `_finish_take` derives `mine` from the SCENE (clip-partition
   curves keyed inside the take's range), runs the pass, registers the
   record with what landed, and reports the three fields. The
   `not_self_contained_note` and its tests are gone. Both routes.
3. **Locks.** A lock is the third thing a key measurably cannot land on.
   author_clip refuses a LOCKED declared channel before the checkpoint via
   `plugwrite.blockers` filtered to `reason == "locked"` (the hint is
   plugwrite's `setAttr -lock false`). A locked PAD channel is skipped and
   named (`is_locked` in `pad_pin_verdicts` and the weight loop). The
   lost-write and lost-pin notes carry their cause inline from
   `swallowed_by` (= `plugwrite.blocker` + the now-public
   `plugwrite.because`), so the dead-end pointer is gone for every cause.
   `_skip_pin_note(what, because)` takes the clause.
4. **The fake is harsher.** `FakeCmds.locked`: setKeyframe → 0, setAttr →
   raises, xform → drops the locked child silently, getAttr(lock=True) per
   child. `TestTheFakeModelsLocks` asserts the model.

## Left outside

- The bake's constant scale curves and non-root translate curves on the
  slot joints are outside the clip model (pre-existing since #774; delete_
  clip's range cut covers translate, not scale). Harmless while constant.
- `_place_root` still catches an `xform` raise for a connection-fed root;
  #802 measured no raise for constraint/curve-driven plugs and #796 measured
  one — the two measurements disagree on the shape and neither is this
  ticket's.
