### Task 1: `apply_delta_mush` handler (headless TDD)

**Files:**
- Create: `maya_plugin/handlers/correctives.py`
- Test: `tests/test_correctives.py`

**Interfaces:**
- Produces: `correctives.apply_delta_mush(params) -> dict` with keys `mesh, delta_mush, worst_edge_ratio_before, worst_edge_ratio_after, max_displacement, warnings`; module constants `APPLY_DELTA_MUSH_KEYS = ("mesh", "smoothing_iterations", "smoothing_step", "pin_border_vertices")`, `DELTA_MUSH_SYNONYMS = {"iterations": "smoothing_iterations", "step": "smoothing_step", "pin_border": "pin_border_vertices", "object": "mesh", "name": "mesh"}`, `MAX_MUSH_ITERATIONS = 50`.
- Consumes: `dispatcher.require_known_keys`, `naming.require_mesh`, `session.auto_checkpoint`, `handlers.sculpt.vertex_positions` (or the module's own re-read helper matching blendshape.py's `_points`).

Handler shape (follow surfdetail.py): lazy `_cmds()`, `validate(params, cmds)` returning resolved values, mutation wrapped in checkpoint with rollback.

Validation/refusals, in order:
1. `require_known_keys`.
2. `mesh` required → `naming.require_mesh` (missing/not-a-mesh refusals come free).
3. `smoothing_iterations`: int (bool refused), 1–50; default 10.
4. `smoothing_step`: float, 0.01–1.0; default 0.5.
5. `pin_border_vertices`: bool; default True.
6. No skinCluster in `cmds.listHistory(shape, pruneDagObjects=True)` → refuse `"apply_delta_mush relaxes SKINNING - '<mesh>' has no skinCluster"`, hint `"bind_skin first"`.
7. Existing deltaMush in history → refuse `"'<mesh>' already has a deltaMush ('<node>')"`, hint `"delete_objects it first - stacked smoothing is unexplainable"`.

Mutation: `cmds.deltaMush(mesh, smoothingIterations=…, smoothingStep=…, pinBorderVertices=…)`. Postcondition (raise + rollback): exactly one deltaMush in history.

Measurement (module-level helper `edge_ratio_report(cmds, mesh) -> float` usable pre/post): worst ratio of CURRENT world edge length to the orig-shape edge length via `OpenMaya.MItMeshEdge` — orig shape = the intermediate shape (`cmds.ls(cmds.listRelatives(mesh, shapes=True, fullPath=True), intermediateObjects=True)`); skip edges with orig length < 1e-9. `max_displacement` = max vertex distance between pre-mutation and post-mutation re-read positions. Warning when every driver joint of the skinCluster has |rotate| < 1e-4 rad on all axes: `"measured at rest - pose the rig to measure the relaxation"`.

### Task 2: `add_corrective` handler (headless TDD)

**Files:**
- Modify: `maya_plugin/handlers/correctives.py`
- Test: `tests/test_correctives.py`

**Interfaces:**
- Produces: `correctives.add_corrective(params) -> dict` with keys `mesh, blend_shape, target, joint, interpolator, pose_name, pose_index, weight_at_pose, weight_at_rest, corrective_displacement, warnings`; constants `ADD_CORRECTIVE_KEYS = ("mesh", "target", "joint", "rotation")`, `ADD_CORRECTIVE_SYNONYMS = {"angle": "rotation", "pose": "rotation", "bone": "joint", "shape": "target", "weight": "target"}`, `ZERO_ROTATION_TOL_DEG = 1e-3`, `DUPLICATE_POSE_TOL_DEG = 1.0`.
- Consumes: `blendshape._blend_node_for(cmds, mesh_shape)` for node resolution (import the module, reuse the helper), `clip.guard_static_pose`, `poseInterpolatorAddPose` MEL helper via `maya.mel.eval`.

Validation/refusals, in order:
1. `require_known_keys`.
2. mesh → require_mesh; no blendShape node → refuse (hint `create_blendshape first`); `target` not an alias on the node → refuse listing valid aliases.
3. `joint` must exist and be `cmds.nodeType == "joint"`.
4. `rotation` = list of 3 numbers (degrees); all |r| < ZERO_ROTATION_TOL_DEG → refuse `"rotation (0,0,0) IS the neutral pose"`, hint `"give the bent pose the corrective should peak at"`.
5. Target alias plug has an incoming connection:
   - source node type starts with `animCurve` → refuse `"a clip owns weight '<t>'"`, hint `"delete_clip first"` (mirror guard_static_weights wording).
   - source is a poseInterpolator → refuse `"'<t>' is already a corrective driven by <interp>"`, hint `"delete_objects the interpolator to re-author"`.
   - anything else → refuse naming the source plug.
6. `clip.guard_static_pose`-equivalent on the driver joint (anim curves on its rotate → refuse; the handler must pose it).
7. Existing interpolator on the joint already holds a pose whose recorded rotation is within DUPLICATE_POSE_TOL_DEG per axis → refuse naming the pose. (Pose rotations re-read by snapshotting: for each existing non-neutral pose, the check runs against the pose's recorded driver rotation — read `pose[i].poseRotation` if readable, else track via pose names + a `mcp_corrective` note attr; the mayapy task pins which read works.)

Mutation flow (checkpoint; `try/finally` restores joint.rotate; rollback deletes a CREATED interpolator and the new connection):
1. Snapshot `joint.rotate`.
2. Find interp: scene `poseInterpolator` shapes whose `driver[0].driverMatrix` source node is the joint. If none: set rotate to (0,0,0); `created = cmds.poseInterpolator(joint, name=unique("<jointShort>_poseInterp"))`; add poses `neutral`, `neutralSwing`, `neutralTwist` via `mel.eval('poseInterpolatorAddPose("<shape>", "<name>")')`.
3. Set rotate to `rotation` (degrees→UI via `units.degrees_to_ui`); `pose_index = poseInterpolatorAddPose(interp, pose_name)` where `pose_name` = target alias (suffix `_2`, `_3`… if taken on this interp).
4. Read mesh vertex positions (skin-only at trigger), `connectAttr("<interp>.output[<pose_index>]", "<bsNode>.<alias>")`, re-read → `corrective_displacement`.
5. `weight_at_pose = getAttr(alias plug)`; if < 0.5 → raise HandlerError (inert wire — the #764 class) and roll back.
6. Restore rotate to (0,0,0)-snapshot… restore SNAPSHOT (rest may legitimately be the snapshot); read `weight_at_rest` with rotate zeroed first, then restore snapshot. `weight_at_rest > 0.01` → warn. `corrective_displacement < 1e-7 × mesh extent` → warn near-identical target.
