# #770 — `maya_bake_mesh_maps`: AO / curvature / normal baked from the mesh itself

**Goal:** Fix the measured, shipped weakness (golem joins fail under SSAO;
`evals/golem_delivery/README.md`): bake geometry-derived maps — ambient
occlusion, curvature, world-space normal — from the meshes in the scene, verify
them, and (opt-in) composite the AO into the material's colour map so the
contact shadow actually ships in the texture.

**How this differs from #714's `maya_bake_textures`:** #714 flattens
*procedural shader networks* through `convertSolidTx`. #770 bakes maps that
come from *geometry* (what occludes what, where edges are, which way surfaces
face) — that needs a renderer, and the engine is Arnold's
`arnoldRenderToTexture`. The two tools compose: #770's AO composite writes a
plain file→slot wiring (#714's measured shapes), so exports stay honest.

**Consumers:** the golem-class delivery (AO shipped in the colour map), and
#775 directed detail (curvature = edge-wear mask, AO = pocket-grime mask,
world-normal G channel = up-facing dust mask).

## Measured facts this plan is built on (probes, `evals/meshmaps_probe_770*.py`)

MEASURED, not assumed. Do not re-litigate without a new measurement.

| Fact | Consequence |
|---|---|
| mtoa loads under `maya.standalone` in ~6s; `arnoldRenderToTexture` runs there | Real bake tests can live in the mayapy suite; probes were run headless |
| The `-shader <node>` flag bakes through a shader that is **never assigned** to the mesh | The bake phase mutates NOTHING — no assign/restore dance, no SG edits. Temp shader nodes are created and deleted, that is all |
| AO **sees other meshes** as occluders (plane under a resting box: mean 3.9 under it vs 251.1 away) | The golem-join contact shadow is exactly what this bakes |
| Output is EXR only (`extension="png"` is silently IGNORED — unknown kwargs do not raise) | Convert; never pass unmeasured kwargs |
| `MImage.readFromFile(exr)` → `writeToFile(png)` works and is **LINEAR** (AO white=0.5 lands on 127/128) | The AO png holds linear values; sRGB base maps must be decoded before the multiply |
| A **UV-less mesh** bakes a *corrupt* EXR: the command returns fine, `MImage.readFromFile` raises `kFailure` later | Refuse UV-less upfront (the #714 idiom); Maya raises in the wrong place, too late |
| Output filename is Arnold's node name: `pPlaneShape1.exr` normally, but `left_part_partShape.exr` on short-name collisions | Never parse the naming rule: bake ONE mesh per call into a private empty temp dir, take the single `.exr` that appears |
| `aiCurvature.output` enum = convex:concave:both; **concave on a beveled cube is honestly ALL-ZERO** | A flat map is a WARNING here, not a refusal — unlike #714, flat can be honest (a lone convex mesh has all-white AO too) |
| `aiUtility` shadeMode=flat + colorMode='n' bakes a rich world-normal (60k distinct values on a sphere) | The normal product is world-space (the mask consumer); tangent high→low is a different capability, deferred |
| `extend_edges=True` pads shells but floods **alpha to 1.0 over the whole image** (0.97 → 1.0 on a sphere) | Padding kills alpha as a "was baked" mask. Single-target composites bake padded; multi-wearer composites bake UNPADDED and mask by alpha |
| Timing: 1024 AO on a 124.5k-tri mesh = 6.2s; 3.4s on trivial meshes; mtoa load ~6s | Per-map budget is seconds; a whole-asset bake fits a normal render timeout |
| aiAO defaults: samples 3, spread 1, falloff 0, farClip 100; aiCurvature: radius 0.1, spread 1, bias 0.5 | Defaults ship as-is; only `curvature_radius`/`curvature_output` are exposed (the #775 wear-mask knobs) |

## Shape

Tool `maya_bake_mesh_maps` → command `bake_mesh_maps` → handler
`maya_plugin/handlers/meshmaps.py`.

Params: `meshes` (req), `out_dir` (req, absolute, existing — texbake rules),
`maps` (subset of `ao|curvature|world_normal`, default all three),
`resolution` (256..4096, default 1024), `apply_ao` (bool, default false),
`curvature_radius` (default 0.1 scene units), `curvature_output`
(`convex|concave|both`, default `convex`).

**Phase A — bake, mutating nothing.** Per (mesh, map): temp shader
(aiAmbientOcclusion / aiCurvature / aiUtility), `arnoldRenderToTexture` into a
private empty temp dir with `shader=`, selection saved/restored; exactly one
EXR expected; MImage→PNG; verify (readable, stats: distinct values, opaque
fraction, mean) — flat warns, unreadable/missing refuses; move to
`<out_dir>/<meshShort>_<map>.png` via `.part` (texbake discipline). Temp
shaders deleted; refuse upfront on requested-mesh short-name collisions.

**Phase B — apply_ao, the only mutation.** Per material worn by requested
meshes (texclaim claims): colour slot must be a plain value or a PNG file
(procedural → refuse, hint `maya_bake_textures` first; wearer outside the
request → refuse). Composite per texel:
`out = srgb_encode(decode(base) * ao_linear)` where decode honours the file
node's colour space (sRGB decode vs Raw passthrough). Single wearer: bake was
padded, whole-image multiply. Multiple wearers (all requested): unpadded
bakes, alpha-masked union, overlap fraction warned. Written as a NEW file
`<material>_color_ao.png` (never overwriting the input — the golem kit atlas
is shared with a consumer), rewired with #714's measured colour-slot shape.
`session.auto_checkpoint` before the first rewire; postcondition: slot
file-backed at the new path.

New module `pngwrite.py`: 8-bit RGB PNG writer (the eval scripts' hand-rolled
`struct`+`zlib` technique, promoted like pngprobe was). No image deps.

   maps, collisions, apply preconditions).

   sphere; UV-less refusal; apply rewire + composite verified by reading the

8. Suites (`--junitxml`), deploy check (ping `restart_required`), ticket.
